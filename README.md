# 🥐 Bakery API

This project is a RESTful API built with **Node.js** and **Express.js**, using **MongoDB** as the database. Development utilizes **nodemon** for automatic server restarts. The codebase is organized into **models**, **controllers**, and **middlewares** for maintainability and scalability.

## ✨ Features

- CRUD operations for bakery resources
- Modular architecture (models, controllers, middlewares)
- MongoDB integration
- Nodemon for development

## 🚀 Getting Started

1. Clone the repository.
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the server:
    ```bash
    npm run dev
    ```

## 📁 Folder Structure

```
/models        # Mongoose schemas
/controllers   # Route logic
/middlewares   # Custom middleware functions
```

## 🛠️ Technologies

- Node.js
- Express.js
- MongoDB
- Nodemon
